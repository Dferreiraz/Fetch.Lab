# 🌐 Fetch.Lab

Laboratório de estudo focado em **consumo de APIs REST** e **manipulação avançada do DOM** com JavaScript Vanilla. 

Este repositório centraliza aplicações desenvolvidas para praticar requisições assíncronas (`fetch`), tratamento de dados (JSON), e renderização dinâmica de interfaces, servindo como ponte entre a lógica básica e o uso de frameworks modernos.

---

## 🚀 Projetos

| Projeto | API Utilizada | Conceito Principal Praticado |
|---------|---------------|------------------------------|
| **[Dragon Ball](./DragonBall/)** | Dragon Ball API | Requisição GET, renderização de listas e cards de personagens. |
| **[Jujutsu Kaisen](./JujutsuKaisen/)** | Jujutsu Kaisen API | Filtragem de dados, manipulação de arrays e exibição de detalhes. |
| **[Naruto](./Naruto/)** | Naruto API | Consumo de endpoints, tratamento de imagens e estados de loading. |
| **[Rick and Morty](./RickAndMorty/)** | Rick and Morty API | Paginação, busca avançada e manipulação de objetos aninhados. |

---

## 🛠️ Tecnologias

- **HTML5** & **CSS3** (Layouts responsivos e Grid/Flexbox)
- **JavaScript ES6+** (Fetch API, Async/Await, DOM Manipulation, Array Methods)

---

## ⚡ Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Dferreiraz/Fetch.Lab.git
   ```

2. Abra o arquivo index.html na raiz de cada projeto ou utilize o Live Server no VS Code.
