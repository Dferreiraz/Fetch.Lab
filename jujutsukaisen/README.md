## 📌 Sobre o projeto

O Jujutsu Kaisen API é um projeto desenvolvido para praticar o consumo de APIs REST utilizando JavaScript puro.

A aplicação realiza requisições à Jikan API para obter informações sobre os personagens do anime Jujutsu Kaisen, utilizando os dados retornados para trabalhar a integração entre uma API externa e uma interface web.

O projeto faz parte dos meus estudos de desenvolvimento Front-End e consumo de APIs.

## 🎯 Objetivos

- Praticar requisições HTTP com JavaScript.
- Utilizar `fetch()` para consumir uma API REST.
- Trabalhar com funções assíncronas e respostas de requisições.
- Interpretar dados no formato JSON.
- Manipular elementos do DOM dinamicamente.
- Desenvolver interfaces com HTML5 e CSS3.
- Compreender a integração entre Front-End e serviços externos.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização da interface.
- **JavaScript:** lógica e manipulação dos dados.
- **Fetch API:** realização de requisições HTTP.
- **Jikan API:** obtenção dos dados dos personagens.

## 🌐 API utilizada

O projeto utiliza a **Jikan API**, uma API REST não oficial que disponibiliza dados do MyAnimeList.

O endpoint utilizado retorna os personagens e seus dubladores associados ao anime Jujutsu Kaisen.

- **Documentação:** https://docs.api.jikan.moe/
- **Endpoint:** https://api.jikan.moe/v4/anime/40748/characters
- **Anime:** Jujutsu Kaisen
- **ID do anime:** `40748`
- **Formato dos dados:** JSON

```bash

```

### 3. Execute a aplicação

Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no Visual Studio Code.
