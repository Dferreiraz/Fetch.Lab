## 📌 Sobre o projeto

O Rick and Morty API é um projeto desenvolvido para praticar o consumo de APIs REST utilizando JavaScript puro.

A aplicação utiliza dados externos para explorar personagens da série Rick and Morty, colocando em prática a integração entre uma API e uma interface web.

Este projeto faz parte dos meus estudos de desenvolvimento Front-End e contribui para consolidar meus conhecimentos em JavaScript e consumo de APIs.

## 🎯 Objetivos

- Praticar requisições HTTP com JavaScript.
- Consumir dados externos utilizando `fetch()`.
- Trabalhar com operações assíncronas.
- Interpretar respostas no formato JSON.
- Manipular elementos do DOM dinamicamente.
- Desenvolver interfaces com HTML5 e CSS3.
- Compreender a integração entre Front-End e APIs REST.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização da interface.
- **JavaScript:** lógica e manipulação dos dados.
- **Fetch API:** realização de requisições HTTP.
- **Rick and Morty API:** fornecimento dos dados dos personagens.

## 🌐 API utilizada

O projeto utiliza a [Rick and Morty API](https://rickandmortyapi.com/), uma API REST que disponibiliza informações sobre personagens, localizações e episódios da série.

- **Documentação:** https://rickandmortyapi.com/documentation
- **Endpoint de personagens:** https://rickandmortyapi.com/api/character
- **Tipo:** API REST
- **Formato dos dados:** JSON

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/Dferreiraz/Fetch.Lab.git
```

### 2. Acesse a pasta do projeto

```bash
cd Fetch.Lab/rickandmorty
```

### 3. Execute a aplicação

Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no Visual Studio Code.
